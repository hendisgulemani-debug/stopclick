🚨 DON'T RUN THAT COMMAND!

Fake verification websites can trick people into running malicious commands on their computers.

HOW THE SCAM WORKS

1. A suspicious website appears.

2. It asks you to press WIN + R.

3. It tells you to open CMD.

4. It asks you to paste a command.

5. Running that command can execute malware.

NEVER RUN UNTRUSTED COMMANDS.

🔒 HOW TO PROTECT YOURSELF

• Never paste commands from random websites.

• Close suspicious verification pages.

• Don't run scripts you don't understand.

• Ask a trusted adult or IT professional if unsure.
